# Employee Management System

## 📌 Project Overview
The Employee Management System is a console-based Java application developed using JDBC to manage employee records in a database. It allows administrators to perform various employee management operations through a menu-driven interface.

## 🛠️ Technologies Used
- Java
- JDBC (Java Database Connectivity)
- Oracle Database 26ai
- SQL
- Eclipse IDE

## ✨ Features
1. Add Employee
2. View All Employees
3. Search Employee by ID
4. Update Employee Details
5. Delete Employee
6. Find Highest-Paid Employee
7. Find Employees by Department
8. Exit Application

## 📚 JDBC Concepts Implemented
- Driver Loading
- Database Connection
- Connection Interface
- PreparedStatement
- ResultSet
- executeQuery()
- executeUpdate()
- Exception Handling
- CRUD Operations

## 🗄️ Database Details
- Database: Oracle Database 26ai
- Table: employee_db
- Operations: INSERT, SELECT, UPDATE, DELETE

## 🎯 Project Objective
The main objective of this project is to gain practical knowledge of Java JDBC, database connectivity, SQL queries, and CRUD operations.
